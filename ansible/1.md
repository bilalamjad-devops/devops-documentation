## 🧠 Key Ansible Terms

### 🔹 **Inventory**
- A file that contains information about **remote servers**.  
- It defines which hosts Ansible will manage and their connection details.  
- Example:  
  ```ini
  [servers]
  server1 ansible_host=public_ip_1
  server2 ansible_host=public_ip_2
  server3 ansible_host=public_ip_3

  [all:vars]
  ansible_python_interpreter=/usr/bin/python3
  ```

### 🔹 **Playbook**
- A **YAML file** that defines tasks to run on remote servers.  
- Example use: installing a web server or updating configurations.

### 🔹 **Module**
- A **small reusable task** in Ansible (like a command or function).  
- Examples:  
  - Install Nginx  
  - Start Docker  
  - Create or update a file  
  - Start a server  

Modules are the building blocks of playbooks.

## ⚙️ Lab Setup Overview

In this lab, we create **one master server** and **three host servers**.  
Ansible is installed on the master server, which controls the hosts.

### 🔹 Install Ansible
```bash
sudo apt update
sudo apt install ansible -y
```

### 🔹 Configure SSH Keys
```bash
cd ~/.ssh
vim ansible_key
# Paste your private key here
# Press ESC then type :wq! to save
pwd  # /home/ubuntu/.ssh
```

### 🔹 Connect to a Host
```bash
sudo ssh -i ~/.ssh/ansible_key ubuntu@<public_ip>
```
This step establishes a **secure shell (SSH)** connection — you’ve entered one server from another securely.

To exit:
```bash
exit
```

## 🧩 Create Inventory File
If `/etc/ansible/hosts` doesn’t exist, you can create your own inventory anywhere and specify its path.

```bash
mkdir ~/ansible
cd ~/ansible
vim hosts
```

Add:
```ini
[servers]
server1 ansible_host=<public_ip_1>
server2 ansible_host=<public_ip_2>
server3 ansible_host=<public_ip_3>

[all:vars]
ansible_python_interpreter=/usr/bin/python3
```

Save and exit (`ESC :wq`).

---

## 🔐 Set Permissions
```bash
chmod 700 ~/.ssh
chmod 600 ~/.ssh/ansible_key
```

---

## 🧪 Test Connectivity
Ping all servers:
```bash
ansible all -m ping -i ~/ansible/hosts --private-key=~/.ssh/ansible_key
```

Check memory usage:
```bash
ansible all -a "free -h" -i ~/ansible/hosts --private-key=~/.ssh/ansible_key
```

Check uptime:
```bash
ansible all -a "uptime" -i ~/ansible/hosts --private-key=~/.ssh/ansible_key
```
